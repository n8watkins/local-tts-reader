How It Works

🔊

Local TTS Reader

A Chrome extension that reads any selected text aloud using a fully local Piper TTS server on your machine — no cloud, no API keys, nothing leaves your computer.

The Flow

  1. 1
    Highlight text on any webpage and right-click it. Choose Read selected text from the context menu.
  2. 2
    The extension's background service worker receives the text and checks if the local Piper server is reachable at http://127.0.0.1:5050.
  3. 3
    If Piper is online, the text is split into sentence chunks and sent one at a time to the local Node.js server, which calls piper.exe and returns a WAV audio file.
  4. 4
    An offscreen document (a hidden browser page) receives each WAV chunk and plays it through the Web Audio API — Chrome's Manifest V3 service workers can't play audio directly, so this workaround is required.
  5. 5
    If Piper is offline and Browser TTS fallback is enabled (see Settings), the browser's built-in voice is used instead.

Profiles

Each profile is a named preset that stores a voice, speed, and volume. Create multiple profiles — for example, one fast voice for articles and a slower one for technical content — and switch between them in the popup with the arrow buttons.
